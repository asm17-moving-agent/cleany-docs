# 프로젝트 개요(Project Brief)

## 요약

끌리니(Cleany)는 **무인 스터디카페 운영자**가 이용자 퇴실 뒤 책상에 남은
물체를 확인하고 처리하는 부담을 줄이기 위한 모바일 매니퓰레이터 프로젝트다.
현재 MVP는 운영자가 Dashboard에서 좌석을 지정해 요청한 뒤 로봇이 해당 좌석을
왕복하고, 책상 위 여러 물체를 관찰하고 처리한 결과를 전후 정보와 함께 제공하는
전체 흐름을 대상으로 한다.

## 한 장으로 보는 Cleany

![무인 스터디카페의 지정 좌석에서 쓰레기를 정리하는 Cleany 로봇과 운영자 Dashboard](<assets/cleany-project-overview-v2.png>)

운영자가 좌석을 지정하면 Cleany가 해당 책상으로 이동해 장면을 관찰하고, 허용된
쓰레기만 처리한 뒤 결과를 전달하는 모습을 나타낸다. 이 이미지는 프로젝트 설명을
위한 AI 생성 개념 이미지이며 실제 조립 상태, Dashboard UI 또는 검증 완료 동작을
의미하지 않는다.

## 현재 MVP

1. 운영자가 Dashboard에서 개별 좌석의 작업을 요청한다.
2. 로봇은 사전에 만든 지도를 사용해 대기 위치에서 해당 좌석으로 자율 이동한다.
3. 작업 전 책상 상태를 관찰한다.
4. 여러 물체의 의미와 처리 순서를 판단하고 허용된 물리 동작을 실행한다.
5. 작업 후 책상 상태를 다시 관찰한다.
6. 로봇은 대기 위치로 복귀하고 Backend와 Dashboard에 전후 결과를 전달한다.

쓰레기는 로봇 탑재 수거함에 넣는다. 분실물 후보도 인식 대상이지만, 발견 이후의
물리적 처리 행동은 아직 정하지 않았다.

## 제품 경계

| 구분 | 현재 방향 |
|---|---|
| 1차 타깃 | 무인 스터디카페 운영자 |
| 핵심 문제 | 퇴실 후 책상 위 잔여물을 운영자가 직접 확인하고 처리해야 하는 부담 |
| 미션 시작 | 운영자의 Dashboard 수동 요청 |
| 미션 단위 | 개별 좌석의 책상 |
| 이동 | 사전 제작 지도 기반 대상 좌석 왕복 |
| 작업 대상 | 책상 위 쓰레기와 분실물 후보 |
| 결과 | 작업 전후 관찰과 최종 미션 상태 |
| 시연 환경 | 사람이 없는 통제된 구역, 작업 구역 밖 감독자와 비상 정지 수단 |

## 아직 검증되지 않은 점

운영자 문제와 제품 가치는 팀이 선택한 가설이다. 실제 스터디카페 운영자 인터뷰나
현장 관찰로 검증한 결과는 아직 없다. 분실물 처리 정책과 정확한 MVP 물체 목록도
열린 질문으로 관리한다.
