## 1. 모델의 역할

Gemini Robotics ER 2는 로봇 관절을 직접 움직이는 제어 모델이 아니라 로봇 시스템의
**고수준 두뇌이자 멀티모달 오케스트레이터**다. ER은 Embodied Reasoning의 약자다.
텍스트·이미지·비디오·오디오로 장면과 작업을 이해하고 개발자가 제공한 로봇 함수 또는
VLA를 호출한다.

```text
사용자 명령 + 카메라 영상 + 음성
                 ↓
        Gemini Robotics ER 2
        ├─ 공간·물체 이해
        ├─ 장기 작업 계획
        ├─ 진행도·성공 여부 판단
        ├─ 실패·안전 상태 감시
        └─ 로봇 함수·VLA 호출
                 ↓
   이동·파지·그리퍼·안전 API
                 ↓
              실제 로봇
                 ↓
           최신 관찰 결과
                 └────────────► ER 2
```

## 2. 같은 계열 모델과의 구분

| 모델                          | 역할                      | 제어 수준             | 사용 가능 여부 |
| --------------------------- | ----------------------- | ----------------- | -------- |
| Gemini Robotics 2           | 영상·언어를 실제 행동으로 연결하는 VLA | 모터 동작에 가까운 하위 행동  | 불가능      |
| Gemini Robotics ER 2        | 계획, 상황 이해, 작업 오케스트레이션   | 고수준 함수·VLA 호출     | 가능       |

ER 2는 작업 대상, 목표, 순서, 재시도와 사람 확인 필요 여부를 선택한다. 실제 파지
자세, 관절 궤적과 모터 명령은 연결된 로봇 실행 계층이 계산한다.

## 3. 주요 기능

### 3.1 영상 기반 진행도 추적

ER 2는 단일 이미지와 연속 영상에서 작업 진행도를 판단한다. 진행도는 다음 5단계로 구분한다.

```text
0~20% → 20~40% → 40~60% → 60~80% → 80~100%
```

이 기능은 물체가 실제로 놓였는지, 컵이 채워졌는지, 물체가 미끄러졌는지 같은 전환 시점을 찾고 실패한 단계만 재시도하는 데 사용한다.

### 3.2 Moment finding

비디오에서 컵이 가득 찬 시점, 물체가 그리퍼에서 미끄러진 시점처럼 다음 행동으로
전환해야 하는 결정적 순간을 찾는다.

### 3.3 함수 호출과 구조화 출력

ER 2 출력은 텍스트 또는 함수 호출이다.
`move_object()`, `inspect_object()`, `skip_object()`, `ask_human()` 같은 고수준 도구를 제공하면, 모델은 호출 이름과 인자를 생성한다.
실제 물리 동작은 애플리케이션이 실행하고 결과를 다시 모델에 보낸다.

### 3.4 여러 로봇의 협업

로봇마다 신체적 능력이 다른 경우 ER 2가 이동·운반·정밀 작업을 분배할 수 있다.

### 3.5 안전 오케스트레이션

ER 2는 위험한 하위 작업 거부, 불가능한 작업 차단, 사람 접근 인지, 추가 질문과 안전
도구 호출을 지원한다. 이 능력은 물리적 안전장치를 대체하지 않는다.

## 4. 성능 참고 수치

다음 값은 독립 검증 전 참고 수치다.

| 평가 | ER 1.6 | ER 2 |

로봇 작업 성공률이 아니라 프레임별 진행 단계 분류 정확도로 구분해야 한다.

## 6. 적합한 역할

- 사용자 명령과 작업 목표 해석
- 이미지·영상·오디오를 결합한 장면 이해
- 장기 작업의 단계 분해와 실행 순서 결정
- 현재 상태에 맞는 고수준 함수 또는 VLA 선택
- 실행 결과와 최신 관찰을 반영한 재계획
- 실패·모호성·추가 확인 필요 여부 판단
- 여러 로봇 또는 도구 사이의 작업 분배
- 작업 진행도와 완료 여부 판단

## 7. 책임 범위 밖의 일

- 최종 로봇 base 기준 3D 좌표 확정
- 6D pose와 quaternion 확정
- 그리퍼 폭·파지력·접촉점 결정
- 충돌 없는 관절 궤적 생성
- 관절 토크와 고주기 서보 제어
- 사람 안전거리와 비상 정지의 유일한 판정
- 물체 중량·작업공간·관절 한계의 최종 검증

## 8. 한계와 안전 경계

ER 2는 프리뷰 상태의 확률적 모델이다.
잘못된 객체 인식, 누락, 진행도 오판, 부정확한 좌표와 잘못된 함수 인자가 발생할 수 있다.
따라서 다음 안전 기능은 로컬에 남겨야 한다.

```text
- 허용된 tool과 목적지 allowlist
- JSON Schema·타입 검증
- 작업공간·관절 한계 검사
- 충돌 검사
- 속도·가속도·파지력 제한
- 사람 접근 감지와 pause
- watchdog·timeout
- 물리적 비상 정지
- 불확실할 때 skip 또는 사람 승인
```

의료·교통처럼 중대한 인명·재산 피해가 가능한 안전 필수 환경에는 사용하지 않는다.
하드 리미트와 비상 정지는 ER 2의 판단과 분리한다.
