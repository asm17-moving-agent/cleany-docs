## 1. 요약

`260722 - 객체 탐지·세그멘테이션 클래스 정의 및 라벨링 가이드라인`의 4.2 클래스 목록(23종)을 기준으로, 각 클래스를 커버할 수 있는 **공개 인스턴스 세그멘테이션 데이터셋**을 조사·매핑한 문서다. 실제 데이터 다운로드는 수행하지 않았으며, 후보 소스·라이선스·규모·확보 절차만 정리한다. 모든 출처는 각 항목에 인라인 링크로 표기했고 9장에 종합했다.

핵심 결론은 다음과 같다.

- **[LVIS](https://www.lvisdataset.org/)(1,203종, 마스크 제공, CC BY 4.0)가 이번 조사의 최대 소스다.** 23종 중 **19종**이 LVIS에 마스크 포함 카테고리로 존재한다. 다만 LVIS는 *federated·long-tail* 데이터셋이라(각 이미지에 일부 카테고리만 주석, rare 클래스는 이미지 1~10장 수준) 소량 클래스는 시드·검증용으로만 충분하다.
- **직접 수집이 필요한 클래스는 5종**이다. `carrier`·`earphone_case`·`cable`·`power_bank`는 LVIS·OI-V7에 전용 카테고리가 아예 없고, `mask`는 LVIS 라벨이 있지만 대부분 "착용" 도메인이라 "버려진 마스크" 장면과 맞지 않아 재수집 대상으로 둔다.
  - 단, `cable`은 [IIT Jodhpur cable-detection](https://universe.roboflow.com/indian-institute-of-technology-jodhpour/cable-detection-liolt)이 2,370장 규모 인스턴스 세그멘테이션으로 확인됐다. 도메인(산업용 전선 위주로 추정)·마스크 품질 검증 후 판정 상향 여지가 있어 3.2 표에는 아직 반영하지 않았다.
- COCO에 있는 `cup`, LVIS의 `paper cup`이 존재하지만 무인 스터디카페 실물(종이컵·텀블러)과 형태 분포가 달라 도메인 보강(재라벨링)이 필요하다는 가이드라인 지적은 유효하다.

이 문서의 클래스 목록은 가이드라인이 draft 상태이므로 확정값이 아니며, 매핑도 사람 검토가 필요한 예비 조사다.

## 2. 조사 전제와 후보 소스

- **작업 유형**: 인스턴스 세그멘테이션(box + polygon/mask). 마스크가 없고 박스만 있는 데이터셋은 별도 표기했다.
- **직접 다운로드 없음**: 각 소스의 공개 위치·라이선스·규모·포맷만 확인. 실제 이미지·annotation은 내려받지 않았다.

| 소스 | 규모 | 마스크 | 라이선스 | 특징 |
|---|---|---|---|---|
| [COCO-Seg](https://docs.ultralytics.com/datasets/segment/coco) | 80종, 학습 118k/검증 5k | polygon | 이미지 Flickr 원저작자, 주석 CC BY 4.0 | Ultralytics YOLO-seg 라벨 즉시 사용 |
| [LVIS](https://docs.ultralytics.com/datasets/detect/lvis) | 1,203종, 학습 100k/검증 20k | polygon | CC BY 4.0 (이미지는 COCO train/val2017 공유) | **본 조사 핵심**. federated·long-tail |
| [Open Images V7](https://storage.googleapis.com/openimages/web/factsfigures_v7.html) | 박스 600종 중 **350종만** 마스크 | mask | 주석 CC BY 4.0, 이미지 CC BY 2.0 | 공통 물체 마스크 다량 |
| [TACO](http://tacodataset.org/) | 60 카테고리/28 상위, 약 1,500 이미지·4,784 주석 | polygon(COCO 포맷) | 이미지 CC BY 4.0(기여자별 상이 가능) | 쓰레기 특화, 소규모 |
| [Roboflow Universe](https://universe.roboflow.com/) | 데이터셋별 상이 | 데이터셋별 | **데이터셋마다 상이** (CC BY 4.0/Public Domain/기타) | 커뮤니티 데이터, 품질·규모 편차 큼 |

> LVIS는 [federated dataset](https://ar5iv.labs.arxiv.org/html/1908.03195)로 카테고리를 이미지마다 전수 주석하지 않으며(`pos/neg_category_ids`로 관리), 1,203종이 long-tail 분포다. 따라서 아래 "LVIS 존재 ✅"는 마스크 라벨이 있다는 뜻일 뿐, 클래스별 인스턴스 수는 rare(1~10장)~frequent(>100장)로 크게 차이 난다.

## 3. 클래스별 데이터 소스 매핑

표기: ✅ 마스크 포함 공개 소스 존재 / 🟡 박스만 또는 부분·근사·소량 / ❌ 공개 세그 데이터 사실상 없음(직접 수집).

표 안의 모든 소스 항목은 원본으로 직접 연결된다.

- LVIS 뒤 `#번호`는 [lvis.yaml](https://raw.githubusercontent.com/ultralytics/ultralytics/main/ultralytics/cfg/datasets/lvis.yaml)의 클래스 인덱스이며, 링크는 해당 클래스가 정의된 줄로 이동한다. 줄 번호가 밀리지 않도록 commit `eb920ec`에 고정했다.
- OI-V7 항목은 공식 [Open Images visualizer](https://storage.googleapis.com/openimages/web/visualizer/index.html)의 클래스 필터로 연결된다. 마스크가 있는 클래스는 `type=segmentation`, [세그 클래스 350종 목록](https://storage.googleapis.com/openimages/v5/classes-segmentation.txt)에 없어 박스만 있는 클래스는 `type=detection`으로 구분했다.
- 링크가 없는 항목은 조사 결과 해당 공개 데이터셋이 없는 경우이며 모두 ❌로 표기했다.

### 3.4 집계

- **공개 마스크로 초기 확보 가능(✅)**: tissue, wrapper, stick, straw, writing_tool, eraser, ruler, earphone, glasses, card, wallet, wristwatch, blanket, cup, desk_lamp, slippers → **16종** (대부분 LVIS 기반, 일부 도메인 보강 필요)
- **부분·소량(🟡)**: receipt, key → **2종** (LVIS rare + 직접 수집 보강)
- **직접 수집 필수(❌)**: carrier, mask, earphone_case, cable, power_bank → **5종**

LVIS 도입 전 초안 대비 확보 가능 클래스가 9종 → 16종으로 크게 늘었다. 다만 LVIS long-tail 특성상 receipt·key·paper cup 등은 인스턴스 수가 적어 실제 학습 충분성은 별도 검증이 필요하다.

판정과 별개로 **LVIS에 카테고리가 존재하는 클래스는 19종**이다(미보유 4종: carrier·earphone_case·cable·power_bank). `mask`·`receipt`·`key`는 LVIS 라벨이 있지만 도메인 불일치 또는 rare 수량 문제로 판정을 낮췄으므로, 인스턴스 수 집계 대상은 ✅ 16종이 아니라 이 19종이다.

## 4. 소스별 확보 절차 (다운로드 미수행, 절차만)

### 4.1 LVIS — 1차 주력
- 위치·라이선스: [lvisdataset.org](https://www.lvisdataset.org/), CC BY 4.0. 이미지는 COCO `train2017`/`val2017`을 공유하고 주석만 LVIS가 제공([ultralytics lvis.yaml](https://raw.githubusercontent.com/ultralytics/ultralytics/main/ultralytics/cfg/datasets/lvis.yaml)).
- 절차: 3장에서 매핑한 LVIS 인덱스(예: `chopstick`#253, `wallet`#1155, `blanket`#109)만 subset 추출 → 4.2 라벨 체계로 class_id 재매핑 → federated 주석 특성상 해당 클래스의 pos/neg 이미지 세트를 확인해 미주석 인스턴스 누락 여부 점검.
- 유의: rare 클래스는 인스턴스 수가 매우 적어 시드·검증용으로만 신뢰. 클래스별 인스턴스 수를 먼저 집계해 임계 미달 클래스는 직접 수집 대상으로 승격.

### 4.2 Open Images V7 — 공통 물체 마스크 증량
- 위치·라이선스: [factsfigures_v7](https://storage.googleapis.com/openimages/web/factsfigures_v7.html), 주석 CC BY 4.0. 350종만 마스크([세그 클래스 목록](https://storage.googleapis.com/openimages/v5/classes-segmentation.txt)).
- 절차: FiftyOne 등으로 `Chopsticks/Drinking straw/Pen/Eraser/Ruler/Watch/Coffee cup/Mug/Plastic bag` 마스크 subset만 받아 LVIS 대비 인스턴스 수가 많은 공통 클래스를 증량 → COCO→YOLO-seg 변환 → class_id 통일.

### 4.3 TACO — 쓰레기 도메인 보강
- 위치·라이선스: [tacodataset.org](http://tacodataset.org/) / [논문 arXiv:2003.06975](https://arxiv.org/abs/2003.06975) / [Kaggle 미러](https://www.kaggle.com/datasets/kneroma/tacotrashdataset) / [Roboflow 미러](https://universe.roboflow.com/mohamed-traore-2ekkp/taco-trash-annotations-in-context). 60 카테고리/28 상위, COCO 포맷.
- 절차: straw·wrapper·컵류 상위 카테고리만 선별 → 세분화된 TACO taxonomy를 4.2 라벨로 병합(병합 규칙 문서화 필요).

### 4.4 Roboflow Universe — 갭·특수 클래스
- 위치·라이선스: 데이터셋마다 상이 → 채택 전 개별 확인 필수. 확인된 후보: 마스크 [JARVIS(1k, CC BY 4.0)](https://universe.roboflow.com/jarvis-hsunk/face-mask-detection-wpzi7), 케이블 [SEwire(281)](https://universe.roboflow.com/sewire/wire-w5gmp)·[cable-seg(28)](https://universe.roboflow.com/yolo-elkjk/cable-segmentation-mfeuz), 슬리퍼·헤드폰·보조배터리 검색 페이지.
- 절차: 후보별 규모·마스크 품질·클래스 정의 일치도 검수 → 채택분만 병합. 품질 편차가 커 시드·보조 용도로 활용, 그대로 주력 학습에 넣지 않음.

### 4.5 COCO-Seg — cup 등 공통
- [coco.yaml](https://docs.ultralytics.com/datasets/segment/coco) 기반 `cup` 필터 추출 → 스터디카페 도메인 이미지로 fine-tune. 이미지 라이선스는 상업 이용 시 개별 확인.

## 5. 권고 확보 전략

1. **1차 시드셋(공개)**: LVIS subset(19종 매핑분) + OI-V7(공통 물체 증량) + TACO(빨대·포장지) + COCO(cup) + Roboflow(마스크). 선행 조건은 **각 소스 taxonomy를 4.2 라벨 체계로 통일하는 변환·병합 스크립트**와 **클래스별 인스턴스 수 집계**.
2. **2차 도메인 보강(직접 수집)**: 무인 스터디카페 실촬영으로 cup(종이컵·텀블러), wrapper, mask(버려진 상태), tissue(젖은/뭉친), slippers, glasses(안경집) 등 도메인 갭 큰 클래스 재라벨링. 260722 가이드라인의 calibration·라벨링 절차 그대로 적용.
3. **3차 신규 수집(공개 부재·소량)**: carrier·earphone_case·power_bank(공개 없음) + receipt·key·cable(소량)은 자체 수집·라벨링. card·receipt는 개인정보 비식별 기준 선행(가이드라인 11장 리스크 연결).

## 7. 리스크

- LVIS long-tail·federated 특성으로 소량·미표시 인스턴스가 학습 편향·누락을 유발할 수 있음.
- 공개셋 도메인 갭으로 시드 학습 후에도 실환경 성능이 낮을 수 있음(특히 cup·mask·slippers).
- Roboflow 데이터의 라벨 정의·품질 불일치가 학습 노이즈로 유입될 수 있음.
- 라이선스 혼합에 따른 배포 제약을 사전 확정하지 않으면 이후 재수집 필요.
- card·receipt·wallet 등 개인정보 포함 가능 물체는 수집·보관·비식별 기준 미비 시 사용 불가.

## 8. 책상 위 물품 Object Detection 데이터셋 (박스 기반, 도메인 참고)

세그멘테이션이 아닌 **object detection(박스)** 데이터셋이지만, "책상 위 물품"이라는 도메인이 무인 스터디카페 시나리오와 가장 가까워 별도로 조사했다. 마스크가 없어 세그 학습에 직접 쓸 수는 없지만, ① 책상 장면의 도메인 이미지 확보, ② 공개 세그가 없는 갭 클래스(cable·earphone·key·card 등)의 박스 라벨 시드, ③ 자체 세그 라벨링을 가속하는 사전 라벨(weak label) 용도로 가치가 있다.

### 8.4 활용 방침

- 세그 학습 데이터로 직접 사용 불가(마스크 없음). 박스→마스크 자동 변환은 부정확하므로 지양.
- `Study desk items`를 **박스 사전 라벨**로 활용해 자체 세그 라벨링 시 클래스 후보·위치를 제시하면 작업 속도 향상 기대.
- OCID 등은 **clutter·occlusion 라벨링 기준**과 EasyLabel 등 도구 참고용으로만.
- 채택 시 각 Roboflow 데이터셋 라이선스 개별 확인 필수.
