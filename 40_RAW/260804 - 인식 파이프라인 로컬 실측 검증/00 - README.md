# 260804 - 인식 파이프라인 로컬 실측 검증

## 1. 문서화 기준

이 문서 묶음은 아직 프로젝트의 확정 기술 결정이 아니다.

- Raw의 실측 기록이며 공식 기술 기준이 아니다.
- 검증은 로봇 저장소가 아니라 **별도 실험용 디렉터리**(`~/Documents/test`, ROS 2 워크스페이스와 무관한 스파이크 코드)에서 진행했다.
  실제 로봇 코드베이스로의 통합은 아직 이뤄지지 않았다.
- 검증 하드웨어는 **Apple M5 Pro(MPS)를 탑재한 Mac**이다.
  목표 배포 장치인 Jetson Orin NX가 아니므로, 이 문서의 속도(fps, 초) 수치는 Jetson으로 그대로 옮길 수 없다.
  API/동작 방식은 장치와 무관하게 유효하다.
- 실시간 추적(`track_realtime.py`)은 RealSense 라이브 카메라로 직접 실행해 확인했다.
  물체가 화면 밖으로 나갔다가 다시 들어와도 SAM2가 재세그멘테이션을 정상적으로 잡는 것까지 확인했다(03번 문서 3.5절). 다만 단발성 확인이며
  다양한 장면·조명·동시 다물체 이탈 패턴에서의 반복 검증은 아니다.

## 2. 검증 범위

`Gemini Robotics-ER 2 → SAM2 세그멘테이션 → depth 역투영 3D 좌표` 파이프라인을 정지 이미지 기준으로 끝까지 연결하고, 로컬 VLM(Qwen3-VL) 대체 가능성과 실시간 추적 프로토타입까지 확장했다.

## 3. 파이프라인 개요

```text
RealSense D435 (RGB-D)
        ↓ color.png, depth.npy, intrinsics
Gemini Robotics-ER 2  ─┬─ (대안) 로컬 Qwen3-VL-2B-Instruct
   box_2d 0-1000 정규화 ┘
        ↓ bbox 프롬프트
SAM2 (ultralytics 래퍼)
   ├─ 정지 이미지: 픽셀 마스크 (fill_ratio로 박스 품질 검증)
   └─ 실시간: SAM2DynamicInteractivePredictor 메모리 추적
        ↓ 마스크 + depth
3D 좌표
   ├─ 정지 이미지: RANSAC 평면 + 방향성 bbox 전체 (estimate_3d.py)
   └─ 실시간: 물체 하나 지목 시 대표 좌표 한 점 (track_realtime.py)
```

두 백엔드(ER 2, Qwen3-VL)는 같은 출력 스키마(`detections: [{label, box_2d}]`)로 맞춰서, 뒷단 SAM2·3D 코드는 어느 쪽이 만든 결과인지 구분하지 않는다.

## 4. 핵심 결론 요약

- 정지 이미지 파이프라인(ER 2 → SAM2 → 3D bbox)은 실측으로 끝까지 연결했고, 치수 오차를 합성 정답 데이터로 mm 단위까지 정량화했다.
- ER 2는 박스 정밀도가 높고 응답이 항상 유효한 JSON이었다. 로컬 Qwen3-VL-2B는 파이프라인 자체는 동일하게 동작했지만 grounding 정밀도가 뚜렷이 낮았다.
- SAM2를 라이브 카메라 추적에 쓰려면 `ultralytics`가 제공하는 세 API 중 `SAM2DynamicInteractivePredictor` 외에는 선택지가 없다(나머지 둘은 소스 코드 확인 결과 이 시나리오에 아예 못 쓴다).
- 3D 좌표는 두 정밀도 등급으로 나눴다 — 평면을 맞춰 방향성 bbox 전체를 내는 무거운 방식(정지 이미지용)과, 물체 하나의 대표 좌표 한 점만 내는 가벼운 방식(실시간용).
- **큰 물체에서 3D 박스가 물체를 못 감싸던 문제는 원인을 찾고 고쳤지만 정확도는 높지 않다.**
- 실시간 추적은 VLM 추론이 끝나 SAM2 시딩이 완료될 때까지(수 초~14초) 카메라나 물체가 움직이면 안 된다는 것도 실측으로 확인했다.

## 6. 사람 검토가 필요한 핵심 항목

- Mac(M5 Pro, MPS) 실측 속도는 Jetson Orin NX 실측치가 아니다. fps·초 단위 수치는 참고용으로만 쓰고 배포 장치에서 재측정해야 한다.
- Qwen3-VL-2B는 "이미 로컬에 받아져 있던 모델"을 그대로 쓴 것이지, 여러 로컬 VLM을 비교해 선정한 결과가 아니다.
  더 큰 체크포인트(4B/8B)나 다른 모델과의 비교는 하지 않았다.
- SAM2 API 선정(`SAM2DynamicInteractivePredictor`)은 `ultralytics` 패키지 소스 코드를 직접 읽어 내린 판단이다.
  라이브러리 버전이 바뀌면 재확인이 필요하다.
- 큰 물체(≥30cm급, 노트북·모니터·사람)의 3D bbox는 합성 검증 범위를 벗어난다.
- 해상도·토큰 수를 줄이면 로컬 VLM 추론을 6.8초까지 단축할 수 있지만 작은 물체를 놓치는 트레이드오프가 있다.
