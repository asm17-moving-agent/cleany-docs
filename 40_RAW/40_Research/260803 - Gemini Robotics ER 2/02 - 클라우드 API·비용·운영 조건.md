# 260803 - Gemini Robotics ER 2 클라우드 API·비용·운영 조건

## 출처

- [ChatGPT 공유 문서: Gemini Robotics ER 2](https://chatgpt.com/share/6a6f8bd0-8ab8-83ee-bee5-081c013dd3bc)

## 1. 인터넷과 실행 위치

공유 답변은 Gemini Robotics ER 2를 Google 서버에서 실행되는 클라우드 API 모델로
설명한다. 공개된 완전 오프라인 로컬 실행 방식은 없으며, 엣지 컴퓨터가 인터넷을
통해 API를 호출한다.

```text
카메라·마이크·로봇 상태
        ↓
Jetson 또는 엣지 오케스트레이터
        ↓ HTTPS 또는 WSS
Gemini Robotics ER 2 API
        ↓ 텍스트·함수 호출
로컬 Task Manager·MoveIt 2
        ↓
SO-101·그리퍼
```

인터넷이 필요한 것은 고수준 추론이다. 비상 정지, 충돌 회피, 속도·힘 제한,
관절 제어와 진행 중 동작의 안전한 취소는 네트워크와 독립된 로컬 계층에 남긴다.

## 2. 답변에 제시된 엔드포인트 구분

| 구분        | 답변에 나온 모델                                | 용도                                 |
| --------- | ---------------------------------------- | ---------------------------------- |
| 일반 API    | `gemini-robotics-er-2-preview`           | 초기 장면, 실행 결과, 실패, 최종 검증의 이벤트 기반 호출 |
| Streaming | `gemini-robotics-er-2-streaming-preview` | 상태 유지 WSS와 실시간 상호작용               |
| Batch     | 일반 모델의 Batch API                         | 영상 로그 분석, 성공 판정, 데이터 라벨링 등 비실시간 처리 |

초기 MVP에는 일반 API가 단순하다. 사람의 중간 음성 지시나 지속 관찰이 필요할 때만
Streaming을 검토한다. 물리적 동작 함수는 한 동작이 끝나기 전에 다음 동작이
선택되지 않도록 `BLOCKING` 형태로 다루는 구성이 답변에 제시됐다.

## 3. 공유 답변 기준 가격

다음 가격은 공유 답변이 “2026-08-01 기준 공식 Gemini Developer API 가격”으로
제시한 값이다. 이 문서에서는 별도로 검증하지 않았으며 실제 적용 전에 공식 가격표,
지역, 티어, 쿼터와 Preview 조건을 확인해야 한다.

### 3.1 일반 API

| 항목 | 무료 티어 | 유료 티어 |
| --- | ---: | ---: |
| 입력 토큰 | 무료 | $2 / 100만 토큰 |
| 출력 토큰 | 무료 | $10 / 100만 토큰 |
| 컨텍스트 캐시 | 미지원 | $0.20 / 100만 토큰 |
| 캐시 저장 | 미지원 | $1 / 100만 토큰·시간 |

입력 단가는 텍스트·이미지·비디오·오디오에 동일하게 적용된다는 설명이며, 출력
가격에는 내부 thinking token이 포함된다고 적혀 있다.

### 3.2 Streaming API

| 항목 | 무료 티어 | 유료 티어 |
| --- | ---: | ---: |
| 입력 토큰 | 무료 | $2 / 100만 토큰 |
| 출력 토큰 | 무료 | $10 / 100만 토큰 |
| 컨텍스트 캐시 | 미지원 | 미지원 |
| Batch API | 미지원 | 미지원 |

### 3.3 Batch API

| 항목 | 답변에 나온 가격 |
| --- | ---: |
| 입력 | $1 / 100만 토큰 |
| 출력·thinking | $5 / 100만 토큰 |
| 컨텍스트 캐시 | $0.10 / 100만 토큰 |

표준 호출의 절반 가격으로 설명됐지만 즉각적인 로봇 제어에는 부적합하다.

## 4. 호출 시점

- 최초 책상 스캔 후 객체 인벤토리와 의미 분류가 필요할 때
- 로컬 인식 결과와 파지 가능성을 바탕으로 우선순위를 정할 때
- 물체 하나의 이동과 검증이 끝났을 때
- 파지 실패, 위치 변경, 모호한 객체 또는 정책 차단이 발생했을 때
- 컵 내용물처럼 추가 검사를 수행한 결과가 나왔을 때
- 최종 장면에서 완료 여부를 검증할 때

## 5. 네트워크 장애 정책

```text
API 정상
→ 고수준 다음 행동을 요청

API timeout·연결 단절
→ 새 행동 시작 금지
→ 진행 중 동작은 로컬 안전 정책에 따라 완료 또는 취소
→ 로봇을 안전 자세로 이동
→ task state와 로그 보존
→ 재연결 또는 사람 개입 대기
```

필요한 구현 요소는 timeout, bounded retry, circuit breaker, watchdog, idempotent tool
result, 이전 interaction ID와 로컬 task ID의 연결이다.

## 6. 데이터와 개인정보

답변은 무료 티어 데이터가 제품 개선에 사용될 수 있고 유료 티어는 그렇지 않은
것으로 가격표에 표시됐다고 설명한다. 카메라와 음성에는 얼굴, 개인 소지품, 대화,
화면 정보가 포함될 수 있으므로 다음 항목을 별도로 검토해야 한다.

- 무료·유료 티어별 데이터 사용 조건
- 이미지·음성의 전송 동의와 최소 수집
- API 요청·응답 로그의 보관 기간과 접근 권한
- 프롬프트, 구조화 출력과 이미지의 개인정보 마스킹
- 실패 재현용 rosbag·JPEG의 암호화와 삭제 정책
- API 키를 코드나 이미지에 포함하지 않는 Secret 관리
