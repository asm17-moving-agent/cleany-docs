# 260715 - 로봇 프레임 구조

## 결정

XLeRobot 상부 모듈과 4륜 Mecanum base를 연결하는 프레임으로 알루미늄 프로파일을
사용한다.

## 이유

- 책상 높이와 arm workspace에 맞춰 상부 높이와 mounting geometry를 조정할 수 있다.
- Jetson, sensor와 로봇 탑재 수거함의 위치를 반복 변경하기 쉽다.
- custom Mecanum base와 체결 구조를 직접 설계할 수 있다.
- XLeRobot 기본 RÅSKOG 치수에 전체 geometry를 맞추는 제약을 줄인다.

## 선택하지 않은 대안

IKEA RÅSKOG는 XLeRobot 기본 조립 자산을 활용할 수 있지만 고정된 치수, custom base
체결과 목표 책상 높이에 대한 제약 때문에 기준 프레임으로 선택하지 않는다.

## 결과

- URDF, collision, base-to-arm transform을 custom geometry로 관리한다.
- 상부 payload, 무게중심, 강성과 진동을 실제 조립에서 검증한다.
- cable routing, sensor 시야와 수거함 접근을 프레임 설계에 포함한다.

## 재검토 조건

- 목표 책상 workspace와 payload를 만족하지 못한다.
- base 안정성, 강성, 조달, 제작 비용이 허용 범위를 넘는다.
- 실제 arm, camera 배치가 선택한 프로파일 geometry와 맞지 않는다.
