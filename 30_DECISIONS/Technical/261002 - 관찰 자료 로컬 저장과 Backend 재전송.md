# 261002 - 관찰 자료 로컬 저장과 Backend 재전송

## 결정

작업 전 사진과 인식 정보는 첫 조작 전에 로컬에 저장한다. 저장에 실패하면 첫
조작을 시작하지 않는다. 저장에 성공하면 Backend 저장 확인을 기다리지 않고
조작을 진행한다.

Backend에는 작업 전 사진과 최종 사진 및 해당 관찰의 인식 정보를 전송한다.
사진 전송은 제한된 자동 재시도와 운영자의 수동 재전송을 지원하며, 같은 관찰 ID를
사용해 중복 저장을 막는다. 전송 재시도는 물체 조작의 재실행과 구분한다.

Backend 저장이 확인되면 로컬 사본을 삭제할 수 있다. 미전송 자료는 별도로 정할
보관 기한을 적용하며, 삭제하더라도 미전송 사실과 사유는 기록에 남긴다.

## 이유

작업 증거를 로컬에 확보하면서 사진 전송 지연이 조작 전체를 막지 않게 한다.
일시적인 전송 실패는 재시도와 수동 재전송으로 처리하고, 원격 저장 확인과 로컬
발행 성공은 구분한다.

## 선택하지 않은 대안

| 대안 | 선택하지 않은 이유 |
|---|---|
| Backend 저장 확인을 첫 조작의 조건으로 사용 | 사진 전송 지연이 조작 시작을 막음 |
| 자동 재시도 없이 수동 재전송만 제공 | 일시적인 전송 실패도 운영자가 직접 처리해야 함 |
| 7일 뒤 삭제를 확정된 기본값으로 사용 | 보관 기간의 수치는 아직 선택하지 않음 |

## 결과

로컬 저장 실패, 전송 대기와 Backend 저장 확인을 구분해 기록한다. 자동 재시도의
한도와 간격, 저장 확인과 중복 판별 계약 및 미전송 로컬 자료의 보관 기한은 추가
확인이 필요하다. 기존 초안의 7일은 검토값이다.

Backend에 저장된 자료의 보관 기간, 접근 권한과 삭제 정책은 이 결정에서 정하지 않는다.

## 재검토 조건

작업 증거의 보존 요구나 로봇 저장 용량으로 로컬 보관과 전송 정책을 유지하기
어려울 때 재검토한다.
