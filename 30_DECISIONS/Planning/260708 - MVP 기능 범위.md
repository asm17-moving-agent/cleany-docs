# 260708 - MVP 기능 범위

## 선택안

1차 MVP를 Dashboard 수동 요청부터 지정 좌석 왕복, 책상 위 물체 처리와 전후 결과
표시까지의 E2E 흐름으로 둔다. 현재 팀이 선택한 방향이며 `selected` 승격은 GitHub
PR의 사람 검토 이력이 생긴 뒤 수행한다.

## 포함 범위

- 운영자가 Dashboard에서 개별 좌석을 선택해 미션 요청
- Backend의 요청·진행 상태·최종 결과 연동
- 사전 제작 지도를 사용한 대기 위치↔좌석 자율 왕복
- 작업 전후 책상 관찰
- 여러 물체의 의미·처리 가능 여부·순서 판단
- 허용된 쓰레기 후보를 로봇 탑재 수거함에 투입
- 실패·미처리 대상과 전후 결과 보고

분실물 후보는 인식 대상이지만 발견 이후의 물리적 행동은 결정하지 않았다.
별도 보관함을 MVP의 확정 구성으로 가정하지 않는다.

## 제외 범위

- 데모 중 Mapping
- 의자 정렬, 바닥 청소, 책상 닦기, 소등과 문단속
- 사람이 함께 있는 환경의 자율 운영
- 범용 자연어 명령과 모든 물체 처리
- 상용 규모 다점포 관제

## 검증 단계

1. Rule-based Planner로 전체 경계를 연결하는 통합 검증
2. AI 계획과 VLA-backed Manipulation을 포함한 목표 MVP
3. 필요할 때만 별도 승인한 축소 범위

현재 성공 기준은 통제된 데모의 pass/fail이며 정량 성공률과 반복 횟수를 만들지 않는다.

## 재검토 조건

- 분실물 행동을 MVP에 새로 포함한다.
- 실제 로봇 제약으로 전체 E2E 흐름을 축소해야 한다.
- Dashboard·Backend를 제외하거나 미션 단위를 변경한다.
- 사람이 있는 환경으로 시연 조건을 넓힌다.
