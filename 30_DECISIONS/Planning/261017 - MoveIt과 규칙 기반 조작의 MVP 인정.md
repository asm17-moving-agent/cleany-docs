# 261017 - MoveIt과 규칙 기반 조작의 MVP 인정

## 결정

MoveIt과 규칙 기반 Manipulation Skill로도 목표 MVP의 조작 실행 기준을 충족할 수
있다. VLA 기반 Skill의 포함을 필수 조건으로 요구하지 않는다.

장면 해석과 처리 순서 제안, 허용된 행동의 검증, 실행 결과 재관찰, 미처리와 실패
보고 및 전체 미션 흐름은 계속 충족해야 한다.

## 이유

기존 성공 기준의 VLA 필수 여부를 질문했고, 사용자가 MoveIt, 규칙 기반으로도 MVP를
충족한다고 답했다. 이 기록은 그 성공 기준을 명시한다. VLA와 MoveIt의 성능 비교나
VLA를 제외한 기술적 우열 판단은 이번 답변에 포함되지 않았다.

## 대안의 처리

VLA Skill 포함을 필수로 두는 기존 성공 기준을 변경한다. VLA 자체를 금지하거나
향후 실험 후보에서 제외하는 결정은 아니다.

## 결과

- 물리 실행은 MoveIt, 규칙 기반 Skill과 controller 경로로 검증할 수 있다.
- 계획 성공, Mock 결과 또는 미검증 놓기를 실제 조작 성공으로 보고하지 않는다.
- 실제 로봇에서 필요한 전체 통합과 승인된 축소 범위의 구분은 유지한다.

## 재검토 조건

새 처리 대상이나 요구 동작을 현재 Skill로 충족할 수 없으면 VLA를 포함한 실행
backend 후보와 검증 기준을 다시 검토한다.
