# 260708 - 1차 타깃 무인 스터디카페

## 결정

Cleany의 1차 타깃을 무인 스터디카페로 두고, 1차 사용자를 스터디카페 운영자로
정한다.

## 이유

- 개별 좌석과 책상이라는 명확한 작업 단위를 정의할 수 있다.
- 퇴실 뒤 남은 물체를 운영자가 확인하고 처리하는 구체적인 문제에 집중할 수 있다.
- Navigation 목표, 책상 작업 공간과 전후 결과를 제한된 데모로 구성할 수 있다.
- 업종 전체를 대상으로 하는 것보다 MVP 범위와 검증 조건이 선명하다.

## 결과

- Planning은 무인점포 일반론보다 스터디카페 운영자와 책상 위 잔여물에 집중한다.
- Dashboard 요청 단위는 개별 좌석이다.
- 다른 무인점포, 바닥 청소, 소등, 문단속은 1차 범위에 포함하지 않는다.
- 실제 운영자 인터뷰와 현장 관찰은 별도 검증 과제로 남는다.

## 재검토 조건

- 운영자 검증에서 핵심 문제가 성립하지 않는다.
- 실제 시험 공간이나 로봇 workspace가 좌석, 책상 시나리오와 맞지 않는다.
- 팀이 다른 업종을 1차 타깃으로 다시 승인한다.
